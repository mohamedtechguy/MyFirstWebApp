My First Web App

The same app, rebuilt with Bootstrap 5 for the Web Technologies module at Sheffield Hallam University.

What I have learnt so far

A web page is written in HTML, which uses tags to tell the browser what each piece of content is.

Bootstrap is a framework of ready-made classes, so I can build a layout by adding class names to HTML instead of writing my own CSS.

What I have used

  • Headings, paragraphs, lists, links and landmarks
  • Forms with labels, a fieldset and a legend
  • JavaScript to check the form and build a list with DOM methods
  • fetch and JSON for a weather API
  • Bootstrap grid, cards, forms, accordion and navbar

My First Web App

Hello! This is my web page for the Web Technologies module at Sheffield Hallam University.

What I have learnt so far

A web page is written in HTML, which uses tags to tell the browser what each piece of content is.

Every page needs a doctype, an html element, a head with a title, and a body that holds the visible content.

Steps to publish a page on GitHub Pages

  1. Write the page in Visual Studio Code and save it as index.html.
  2. Create a public repository on GitHub and upload index.html.
  3. In Settings, choose Pages and select the main branch and the root folder.
  4. Wait a minute or two, then open the web address that GitHub gives you.

HTML and CSS I have used

  • h1 and h2 for headings, p for paragraphs, b for bold text
  • ol, ul and li for lists, a for links, img for images
  • header, main, section and footer for page landmarks
  • an external stylesheet (style.css) instead of style attributes
  • a media query that changes the layout on wider screens
